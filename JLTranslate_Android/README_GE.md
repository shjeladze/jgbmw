# JL Translate for Android

**ქართული ↔ ინგლისური** ტექსტის თარგმანი WhatsApp-ისთვის. ეს პროგრამა არ არის Meta/WhatsApp-ის ოფიციალური აპი.

- Incoming WhatsApp/WhatsApp Business notifications: notification access permission, English preview translated into a second Georgian notification.
- WhatsApp composer: optional Accessibility permission, KA → EN overlay appears in WhatsApp. Tap to replace Georgian draft with English translation. Sending always remains manual.
- Manual translation and copying, sharing.
- Google ML Kit models download once using Wi-Fi; text translated locally.
- App permissions are optional and can be turned off.

Android 8+, build with Gradle 8.7, Android Gradle Plugin 8.6.1, JDK 17, Android SDK 35.
